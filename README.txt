## How to use

1. Open `index.html` in a browser.
2. Replace the placeholder leader photographs in `images/`.
3. Replace the graduate photographs in `images/`.
4. Edit names/details directly inside `graduates.html`.
5. If the graduation date changes, edit the `targetDate` line in `js/script.js`.
6. Upload the whole folder to your hosting service.

## Important

Both HTML pages use the same `css/style.css` and `js/script.js`.
The website is responsive and includes a mobile hamburger navigation.
